# CityCruze

Early web MVP for a Hyderabad self-drive rental marketplace. The current screen is a frontend prototype with illustrative sample cars; it does not check inventory, create bookings, or accept payments.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm run dev` and open http://localhost:3000.

## Project direction

The supplied planning documents are in [`citycruze-docs/`](citycruze-docs/README.md). They describe a proposed Next.js, TypeScript, NestJS, PostgreSQL and Prisma stack. This first increment establishes the customer discovery page; vendor, admin and API applications remain future work.

Before live bookings, validate operator and vehicle eligibility, insurance, customer verification, contracts, payments and applicable legal obligations with qualified advisers. The supplied business and compliance assumptions are not approvals.
